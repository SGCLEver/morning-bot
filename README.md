# Личный утренний бот

Telegram-бот, который:

- **в 06:30** (Уфа, UTC+5) присылает сводку: погода, задачи Todoist на сегодня и просроченные,
  дедлайны пробников и олимпиад, важные письма mail.ru (рассылки отсеиваются);
- накануне и в день дедлайна присылает отдельное напоминание;
- **в 22:00** присылает итог дня: что сделано, погода на завтра, по воскресеньям статистика недели,
  и список невыполненного с галочками. После нажатия «Перенести на завтра» отмеченные задачи
  переносятся (время и повторяемость сохраняются). Кнопки обрабатывает Cloudflare Worker, в том числе после полуночи.

Сводки, почта и напоминания работают в GitHub Actions (`bot.py`, стандартная библиотека Python). Меню и кнопки Telegram обрабатывает Cloudflare Worker. Изменения школьного расписания и отметки об уведомлённых версиях хранятся в Cloudflare KV (`BOT_SETTINGS`), а не в Todoist. Исходное расписание остаётся в Worker.

В Cloudflare Worker подключены KV namespace `morning-bot-settings` как `BOT_SETTINGS` и Version metadata как `CF_VERSION_METADATA`. Сам Worker развёртывается в Cloudflare отдельно от Python-кода.

## Секреты (Settings → Secrets and variables → Actions → Secrets)

| Имя | Что это |
|---|---|
| `TELEGRAM_TOKEN` | токен бота от @BotFather |
| `TELEGRAM_CHAT_ID` | твой ID в Telegram (узнать у @userinfobot) |
| `TODOIST_TOKEN` | Todoist → Настройки → Интеграции → Для разработчиков |
| `MAILRU_EMAIL` | адрес почты mail.ru |
| `MAILRU_APP_PASSWORD` | пароль для внешних приложений mail.ru (не основной пароль) |

## Настройка почты (Variables, по желанию)

- `MAIL_VIP`: адреса или домены через запятую, которые показываются всегда (например `kpfu.ru,fa.ru,gosuslugi.ru`).
- `MAIL_BLOCK`: адреса или домены, которые не показываются никогда.

## Проверка

Вкладка **Actions** → «Утренняя сводка» или «Вечерний итог» → **Run workflow**. Ручной запуск приходит сразу, без ожидания времени.

## Напоминания о занятиях

В названиях Todoist распознаются онлайн-занятия, «Зачет»/«Зачёт», «Консультация» и их склонения. Нужны дата и время. Напоминание приходит примерно за 30 минут; workflow `remind.yml` будит cron-job.org каждые 10 минут. При включённой паузе уведомления не отправляются.

## Редактирование уроков в Telegram

- `/schedule` — справка; `/schedule пн` — недельный шаблон; `/schedule завтра` — расписание с заменами.
- `/lesson пн 3 История | 316` — изменить третий урок каждый понедельник.
- `/lesson завтра 3 Русский язык | 418` — разовая замена; можно указать дату ГГГГ-ММ-ДД.
- `/lesson пн 3 История | 316 | хожу` — явно указать посещение: «хожу», «иногда», «окно».
- `/cancel_lesson завтра 3` — отменить урок на выбранную дату.
- `/bell 3 10:20 11:00` — изменить звонки для всех дней; пересечения отклоняются.
- `/reset_schedule пн` — вернуть исходный недельный день; `/reset_schedule завтра` — убрать разовые замены.
- `/reset_schedule звонки` — восстановить исходные звонки.
- `/undo_schedule` — отменить последнее изменение расписания.

Разовая замена важнее недельного шаблона. Команды доступны только владельцу бота. Изменения KV могут распространяться между узлами Cloudflare до минуты; отправляйте правки по одной и дожидайтесь ответа.

## Версии и уведомления

- `/version` и кнопка «Версия» показывают версии двух частей бота.
- GitHub: `gh.<первые 8 символов коммита>`. Workflow `update.yml` проверяет код и тесты, затем сообщает об изменении Python-кода или workflows в main. Keepalive и правки одного README не вызывают уведомление.
- Cloudflare: `1.1.0+cf.<ID версии>`. Первый запрос к production после deploy сообщает о новой версии. Preview уведомлений не отправляет. Повторные запросы той же версии подавляются отметкой в KV.
- Перед будущим выпуском Worker нужно обновлять текст изменений в `notifyWorkerUpdate`; ID развёртывания меняется автоматически через `CF_VERSION_METADATA`.

Проверка Python: `python -m unittest -v test_bot`.
